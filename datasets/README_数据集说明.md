# 莱势明 AI 排产教学平台 · 真实业务模拟数据集 v2.0

本数据集是「AI 赋能数据驱动的注塑排产优化」案例配套的莱势明汽车饰件公司业务数据集。
所有数据基于真实业务结构（29 台机器、250 个 SKU、20 个客户）按合理分布随机生成，
保留了真实业务的统计特征（如 setup 时间分布、故障率分布、不良率分布等），可用于：

  · 异构并行机调度 MIP / 启发式算法实验
  · 加工时长预测的回归 / SHAP 解释性分析
  · 排产健康度诊断与行业对标
  · 数据治理（异常检测、缺失填补、特征工程）
  · ROI 评估与 Monte Carlo 仿真

## 与 v1.0 的区别

- 工单等 4 张主表全部扩充 5-10 倍
- 新增 7 张业务表（质量、物料、能耗、班次、维修、库存）覆盖更完整的运营场景
- 单 SKU 数量从 218 提升至 ~250
- 时间跨度从 24 个月扩展到 28 个月（2024.01 - 2026.04）

## 字段说明

每张 CSV 的字段含义详见同名 *.schema.json 文件（如 work_orders.schema.json）。

## 使用提示

- 所有 CSV 文件均为 UTF-8 with BOM 编码，Excel 可直接打开中文表头
- 时间字段统一为 ISO 8601 格式（YYYY-MM-DD HH:MM:SS）
- 数据规模可在 ParamLab、DataPilot 等应用中按"数据集大小"切换使用

## 数据生成可复现性

数据生成种子（random seed）= 20260518。如需重新生成或扩展，请运行：
    python3 scripts/expand_datasets.py
