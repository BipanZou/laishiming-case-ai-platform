# SchedulePilot 主提示词

## 角色
你是一名同时精通排产决策与人机交互的运营管理教授。

## 任务
开发单文件 HTML 让 MBA 学员体验"人 + AI"协同排产决策：
- 6 类 What-If 场景（基准 / 紧急插单 / 设备故障 / 节假日加班 / P0 优先级 / 节能模式）
- 4 种排产方案对比（FCFS / EDD / GA / 鲁棒 ALNS）
- 多目标评分（Cmax / 准时率 / 总延迟 / 换模 / 综合）
- 自然语言决策报告生成
- AI 对话答疑（"哪些订单会延迟？""如何降低换模？"）

## 约束
- 真实可运行排产引擎
- 一键场景切换 < 2 秒
- 彩色甘特图 + 悬停 tooltip

## 反思
人是否始终保有最终决策权？AI 给出的建议是否可解释？
