# AlgoLab 主提示词（教学型 Prompt 模板）

## 角色（Role）
你是一名同时精通元启发式算法与可视化交互设计的算法教授。

## 任务（Task）
开发单文件 HTML 应用 AlgoLab，让本科生在浏览器内实时观察 GA / SA / TS / ALNS 四种元启发式算法的演化过程。

## 约束（Constraints）
- 单文件 HTML + 引入本地 lib/chart.min.js，3000+ 行业务代码
- 4 种算法全部前端 JS 实现（不依赖后端）：
  · GA：双层编码（机器分配 + 同机内顺序）+ POX 交叉 + 锦标赛 + 精英 + SA 局部精炼
  · SA：Metropolis 准则 + 3 邻域算子 + 自适应温度 + 重加热
  · TS：禁忌表 + Aspiration + 长期记忆 + 多样化重启
  · ALNS：3 Destroy + 3 Repair + 自适应权重 + Roulette 选择
- 5 个真实业务规模实例（5×3 / 12×5 / 30×8 / 50×10 / 80×29）
- 实时甘特图（彩色订单 + 换模条带 + 延迟红框）
- 实时收敛曲线（当代最优 + 历史最优双线）
- 算法专属诊断图（GA 多样性 / SA 温度 / TS 禁忌表 / ALNS 算子权重）
- 4 算法 Benchmark 并行运行 + 对比卡
- CSV / JSON 导出 + 实验历史（最近 20 次）
- 22 个可调参数（每算法 6-7 个）
- 多目标加权（Cmax / 总延迟 / 总换模）3 个滑块
- 全部中文 UI

## 输入示例（One-shot Example）
点击"启动算法" → 选 GA → 选 30×8 实例 → 3 秒内完成 200 代演化 → 实时更新甘特图、收敛曲线、种群多样性

## 输出格式（Output Format）
完整 HTML：
- 顶部状态栏（运行状态、迭代/总数、当代最优、历史最优、Cmax/延迟/换模、耗时）
- 左侧教学侧边栏（GA/SA/TS/ALNS 各一节，含伪代码 + 复杂度 + 文献引用）
- 中部可视化区（甘特图、收敛曲线、诊断图）
- 右侧实验记录与导出（Benchmark 卡 + 历史 + CSV/JSON）

## 反思（Self-Critique）
1. 4 算法的实现是否真实可运行（而非占位 demo）？
2. 80×29 全厂规模能在 60 秒内完成？
3. 教学侧边栏对学生是否友好？
4. 实验历史能复现吗（JSON 导出后能重现）？
