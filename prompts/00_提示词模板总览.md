## 使用方法

1. 在通义灵码、Cursor、字节 Trae 等支持的 IDE 中粘贴对应主提示词
2. 国产大模型（DeepSeek-V3 / Qwen2.5-Max / GLM-4 Plus）一次性生成 2000-5000 行 HTML
3. 教师在浏览器中试运行验证，记录改进点
4. 追加"修订型 Prompt"驱动迭代
