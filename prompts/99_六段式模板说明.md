# 教学型 Prompt 六段式结构说明

## 一、为什么需要"教学型 Prompt"

普通 Prompt 多服务于"产品开发"目标——让大模型按需求写代码。
教学型 Prompt 服务于"教学目标"——让生成的代码同时满足：
- 学生看得懂（注释、变量命名、UI 文案均为教学语言）
- 学生用得上（不需要安装 Python、不需要联网）
- 学生学得会（每个算法都有理论说明、伪代码、参考文献）
- 学生记得住（每个交互都有可视化反馈）

## 二、六段式结构

### 1. 角色（Role）
明确大模型扮演的角色。例：
- "你是一名同时精通整数规划与管理学院教学法的资深教授（Pinedo + Wolsey 风格）"
- "你是一名既擅长机器学习又擅长用 30 秒讲清概念的本科生导师"

### 2. 任务（Task）
明确要做什么。要让大模型生成的代码同时承担"工具"与"教材"双重角色。

### 3. 约束（Constraints）
列出技术约束（单文件 HTML、引入本地库）+ 教学约束（中文 UI、必须含伪代码）。

### 4. 输入示例（One-shot Example）
给一个完整的"输入→输出"对，让大模型理解期望。

### 5. 输出格式（Output Format）
明确返回的代码结构（顶部教学引导 + 中部模板选择 + 输出区）。

### 6. 反思（Self-Critique）
让大模型在生成后自检：MBA 学员零编程基础能用吗？代码能真实运行吗？

## 三、对其他教师的建议

- 替换"任务"与"约束"两段即可复用
- 保留"反思"段，能显著提升代码质量
- 每个应用建议先生成 v0 版本（粗糙）→ 5-10 次迭代 Prompt 修订 → v1 上线
