## 关键技术决策

### 为什么选单文件 HTML 而不是 React/Vue
- 避免 Node.js 安装门槛
- 双击启动、断网可用
- 评审专家能在 30 秒内运行起来

### 为什么全栈国产 AI
- 数据安全合规要求
- 自主可控（避免 OpenAI/Anthropic API 受限）
- 中文运筹术语精准（DeepSeek 中文表现更好）
- 教育场景成本低（Qwen2.5-Max 学术免费）

### 为什么用 Chart.js 而不是 D3
- 上手简单（学员可二次开发）
- 默认样式优于 D3
- 文件大小适中（~200 KB 离线版）
