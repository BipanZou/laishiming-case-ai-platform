  莱势明 AI 排产教学平台 · 配套资源 v2.0 · 使用说明
================================================================

【本资源包含】
- 7 个真实可运行的 AI Web 应用（断网双击即开）
- 14 张莱势明业务数据表（共 572,505 行）
- 7 份 App 独立使用手册（PDF，docs/app_manuals/）
- 6 份 Python Notebook 等效代码（notebooks/）
- 11 份提示词全集 + 开发记录（prompts/）
- 平台总览页 index.html
- Chart.js 离线版（lib/）

----------------------------------------------------------------
  最快启动方式
----------------------------------------------------------------

方法 1（推荐）：双击 index.html → 浏览器打开平台总览 → 点击任一应用卡片

方法 2：进入 apps/ 子文件夹，双击任一 HTML 文件

无需安装任何软件、无需联网、所有依赖已本地化。

----------------------------------------------------------------
  运行环境
----------------------------------------------------------------

· 浏览器：Chrome / Edge / Safari / Firefox 任意现代版本
· 操作系统：Windows 10+ / macOS 10.13+ / Linux Ubuntu 20.04+
· 网络：完全离线可用
· 硬件：普通办公电脑即可
· Python（可选，仅 notebooks/ 用）：3.8+，
  pip install pyomo pandas scikit-learn matplotlib shap
