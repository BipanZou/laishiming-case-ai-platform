🎓教学场景推荐

⭐ 推荐用于首次接触本案例的 MBA 课堂。重点演示 DiagnosePilot、SchedulePilot、ROILab、ModelTutor 四个应用，让学员在 90 分钟内完整体验"诊断—决策—评估"管理闭环。

时段内容应用学员产出
0–10 min案例导入：莱势明排产困境 + 张总转型动机—问题清单
10–30 min排产健康度 AI 诊断 + 行业对标 + 7 项目 ROI 排序DiagnosePilot改进项目 Top 3
30–55 min6 类 What-If 场景 + 4 方案对比 + LLM 报告生成SchedulePilot决策建议书
55–80 min6 维 ROI 滑块 + Monte Carlo 10K 仿真 + TornadoROILab三方案 NPV 对比
80–90 min小组发言：你们公司值得投这个 AI 吗？—3 分钟董事会汇报

适合两次连续课程（每次 90 分钟）。第一次课覆盖前 4 个 App（诊断→治理→建模→学习），重点是"问题认知 + 数据准备 + 模型构建"；第二次课覆盖后 3 个 App（算法→决策→评估）+ 综合讨论。

第一次课（90 分钟）

时段内容应用
0–25 min排产健康度诊断 + 数据治理DiagnosePilot DataPilot

55–85 minOLS / Ridge / Lasso / RF 4 算法对比 + SHAPParamLab
85–90 min第一次课总结 + 课后作业布置—

时段内容应用

30–55 min6 What-If 场景 + 人机协同决策SchedulePilot
55–80 minNPV / IRR / Monte Carlo 商业价值评估ROILab
80–90 min综合讨论 + 课程结业小组汇报—

本科课堂重点 4 个偏技术应用（Data / Model / Param / Algo），培养"建模 + 算法 + 数据"硬核能力。考核包括 Python 代码作业。

课堂部分（4 学时）
