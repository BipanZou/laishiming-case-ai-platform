📐 普通最小二乘 (OLS)

线性回归最基本的方法。假定 y = Xβ + ε，β 为系数向量。OLS 通过最小化残差平方和 (RSS) 求解 β。

① 目标函数

β̂ = arg min ‖y − Xβ‖²2

② 闭式解

β̂ = (XTX)−1 XTy

③ Gauss-Markov 定理

当误差项 ε 满足零均值、同方差、无自相关时，OLS 是 BLUE（最佳线性无偏估计量）。

④ 优缺点

  • 优点：闭式解、可解释、统计推断完善
  • 缺点：对多重共线性敏感、易过拟合、对异常值敏感
参考：Gauss C.F. (1809). Theoria Motus Corporum Coelestium. · Hastie T. et al. (2009). The Elements of Statistical Learning.

🎯 岭回归 (Ridge)

Hoerl & Kennard (1970) 提出。在 OLS 目标函数上加 L2 惩罚项，对所有系数同时收缩。适合处理多重共线性。

① 目标函数

β̂Ridge = arg min { ‖y − Xβ‖² + λ ‖β‖²2 }

② 闭式解

β̂Ridge = (XTX + λI)−1 XTy

③ 关键性质

  • 对所有 β 同比例缩小（shrinkage）
  • 不能让系数变成精确的 0（只能"接近 0"）
  • λ ↑ → 偏差 ↑、方差 ↓
  • 当 XTX 病态时显著优于 OLS

④ 与 OLS 等价性

当 λ = 0 时 Ridge 退化为 OLS；当 λ → ∞ 时所有系数 → 0。

参考：Hoerl A.E., Kennard R.W. (1970). Ridge regression: Biased estimation for nonorthogonal problems. Technometrics, 12(1), 55–67.

🪢 Lasso 套索回归

Tibshirani (1996) 提出。L1 惩罚导致部分系数被精确地压缩为 0，实现"自动特征选择"。

① 目标函数

β̂Lasso = arg min { ‖y − Xβ‖²/2n + λ ‖β‖1 }

② 求解方法

无闭式解。本案例采用坐标下降法 (Coordinate Descent)：

// Lasso 坐标下降 for iter = 1 to maxIter do for j = 1 to p do r_j ← y − ∑(k≠j) X_k · β_k z_j ← ⟨X_j, r_j⟩ / n β_j ← S(z_j, λ) // 软阈值算子 end for end for // 软阈值算子 (Soft-Thresholding) S(z, λ) = sign(z) · max(|z| − λ, 0)

③ 几何直觉

L1 约束在系数空间是菱形（有"角"）；L2 是球形（光滑）。因此 Lasso 的最优解常落在"角"上（部分系数为 0），而 Ridge 的解一般是非零的。

④ 选择 OLS / Ridge / Lasso

  • 无多重共线性 + 样本充足 → OLS
  • 有多重共线性 / 想稳定预测 → Ridge
  • 想自动特征选择（稀疏解）→ Lasso
  • 想兼具二者优势 → Elastic Net (L1+L2)
参考：Tibshirani R. (1996). Regression shrinkage and selection via the lasso. JRSS-B, 58(1), 267–288.

🌲 随机森林 (Random Forest)

Breiman (2001) 集成大量决策树降低单棵树的高方差。两个核心随机性：① 行抽样（bootstrap）② 列抽样（每节点随机选 √p 个特征）。

① 训练过程

// Random Forest 训练（回归） for t = 1 to nTrees do Bootstrap_t ← 从 D 有放回抽样 n 次 Tree_t ← buildTree(Bootstrap_t, maxDepth, minLeaf) end for // 预测 ŷ(x) = mean(Tree_1(x), Tree_2(x), ..., Tree_T(x)) // 单棵树节点分裂 for each candidate feature (随机选 √p 个) do for each split value do compute MSE_reduction = MSE_parent − (n_L/n)·MSE_L − (n_R/n)·MSE_R end for end for choose best (feature, split) → recurse on left & right

② 优势

  • 对非线性、高维数据效果好
  • 自带特征重要性
  • 不易过拟合（树多时）
  • 处理缺失值能力较强

③ 局限

  • 训练慢（大数据时）
  • 外推能力弱（叶节点为均值）
  • 解释性弱于线性模型
参考：Breiman L. (2001). Random forests. Machine Learning, 45(1), 5–32.

🔍 SHAP 可解释 AI

Lundberg & Lee (2017) 基于博弈论 Shapley 值的统一可解释框架。回答"每个特征对单次预测的贡献是多少？"

① Shapley 值的本质

在合作博弈中，每个玩家(特征)的"应得回报"通过其在所有可能联盟中的"边际贡献"加权平均得到。

φi = ΣS ⊆ N \ {i} [|S|! (n − |S| − 1)! / n!] · [f(S ∪ {i}) − f(S)]

② 三大性质

  • 有效性：所有 φᵢ 之和 = 模型输出 − 基准值
  • 对称性：相同贡献的特征获得相同 φ
  • 线性性：可分解到子模型

③ Permutation 近似

精确计算 SHAP 需 2p 次模型评估（NP-hard），本案例采用 permutation importance 近似：

// Permutation Importance baseR2 ← evalR2(model, X, y) for j = 1 to p do totalDrop ← 0 for k = 1 to nPerm do X_perm ← X with column j 随机置换 drop ← baseR2 − evalR2(model, X_perm, y) totalDrop += drop end for importance[j] = totalDrop / nPerm end for

④ 局部 vs 全局解释

  • 全局：特征整体重要性排序
  • 局部：单条样本的贡献分解
参考：Lundberg S., Lee S.-I. (2017). A unified approach to interpreting model predictions. NIPS.
